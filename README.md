# Telegram Mini App — стартовый экран

Минимальное статическое Telegram Mini App для проверки инфраструктуры.

## Локальный запуск

Откройте `index.html` в браузере или запустите любой статический HTTP-сервер из корня проекта. В обычном браузере Telegram SDK недоступен, поэтому приложение безопасно показывает экран без вызовов API Telegram.

## Публикация

Проект предназначен для статического deployment на Vercel. Production HTTPS URL нужно указать в BotFather как **Web App URL**.

## Безопасность

В проекте нет токенов бота, секретных ключей, паролей или серверной части.
