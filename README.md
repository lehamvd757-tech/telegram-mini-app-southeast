# Telegram Mini App — анкета покупателя

Статическое Telegram Mini App на HTML, CSS и vanilla JavaScript. Сценарий: стартовый экран → анкета → проверка данных → подтверждение формирования заявки.

Заявка формируется только в оперативной памяти страницы. Проект не содержит backend, Bot API, хранилище или отправку данных во внешние сервисы.

## Telegram

Подключён официальный [Telegram Web Apps SDK](https://telegram.org/js/telegram-web-app.js). При запуске внутри Telegram приложение вызывает `ready()` и `expand()`, подставляет `first_name` в поле имени, если он доступен, и использует Telegram ThemeParams в CSS.

## Локальный запуск

Откройте `index.html` в браузере или запустите статический HTTP-сервер из корня проекта. В обычном браузере интерфейс остаётся работоспособным: вызовы Telegram API безопасно пропускаются.
